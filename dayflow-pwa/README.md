# DayFlow PWA — простой задачник

Первая рабочая версия PWA: **День / Задачи / Проекты**, матрица Эйзенхауэра, SQLite и голосовой ввод.

## Что уже работает

- Экран **День**: «Сейчас» (до 3 задач) и «Сегодня».
- Экран **Задачи**: просмотр по срокам и по матрице Эйзенхауэра.
- Экран **Проекты**: рабочие/личные проекты, переход внутрь проекта.
- Создание, редактирование, выполнение и удаление задач.
- Перенос задачи в «Сейчас» и смена срока.
- SQLite — задачи сохраняются после перезапуска.
- PWA: можно установить на домашний экран.
- Голосовой ввод:
  - сначала используется браузерное распознавание речи, если оно доступно;
  - если его нет, приложение записывает аудио и отправляет на `/api/transcribe`;
  - серверная расшифровка работает при заданном `OPENAI_API_KEY`.
- После голосового создания показывается **«Отменить»**.

## Запуск локально

### Windows

```bat
setup_windows.bat
run_windows.bat
```

Открыть: `http://localhost:8000`

### Linux / Ubuntu

```bash
chmod +x setup_linux.sh run_linux.sh
./setup_linux.sh
./run_linux.sh
```

## Важное про микрофон

На телефоне доступ к микрофону обычно требует **HTTPS** (localhost — исключение для локальной разработки). Для размещения на сервере лучше поставить Nginx + SSL.

API-ключ OpenAI хранится только на сервере и **никогда не передаётся в браузер**.

## Следующие логичные этапы

1. Авторизация пользователя.
2. Настоящие календарные даты вместо укрупнённых сроков.
3. Напоминания / push-уведомления.
4. AI-разбор естественной речи вместо локальных правил.
5. Telegram-бот как дополнительный канал быстрого добавления.
